# Linux aplicado a IAM

Esta área demonstra como identidade, grupo, processo, arquivo e serviço se relacionam em um host Linux.

## Conteúdo

- UID, GID, usuários e grupos;
- `/etc/passwd`, `/etc/group` e estado de contas;
- ownership, permissões e acesso permitido ou negado;
- conta nominal, conta de serviço e root;
- SSH, sudo e privilégio mínimo;
- logs de autenticação e diagnóstico.

## Laboratórios planejados

1. `01-jml-local`: criação, movimentação, bloqueio e revogação de identidades.
2. `02-ssh-sudo`: autenticação por chave e autorização mínima com sudo.
3. `03-auth-troubleshooting`: falha controlada, análise de log, correção e reteste.

## Publicação

Os exercícios completos são executados localmente no WSL. Este repositório recebe apenas documentação, comandos essenciais e evidências sanitizadas.
